# مبدل تومان و دلار (IRT ⇄ USD Converter)

اپ تبدیل تومان به دلار و بالعکس، با نرخ لحظه‌ای واقعی (نه دستی)، به‌عنوان تسک کارآموزی/استخدام فرانت‌اند.

🔗 **دمو:** بعد از فعال‌سازی GitHub Pages، لینک صفحه در همین‌جا قرار می‌گیرد
(مثلاً `https://USERNAME.github.io/REPO-NAME/`)

---

## توضیح تسک

طبق توضیحات داده‌شده، هدف ساخت یک اپ ساده بود که:

- واحد دلار را از کاربر دریافت کند و به تومان تبدیل کند و بالعکس، بر اساس
  **نرخ واقعیِ لحظه‌ای** (نه یک عدد دستی و فرضی).
- پروژه ساده نگه داشته شود.
- از TypeScript استفاده شود (امتیاز محسوب می‌شود).
- بدون node، به‌صورت Public در گیت‌هاب کارجو قرار گیرد.
- در همه‌ی دستگاه‌ها ریسپانسیو باشد.

## نحوه‌ی کار اپ

به‌محض بازشدن صفحه، اپ نرخ لحظه‌ای دلار به تومان را از یک منبع عمومی و
رایگان دریافت می‌کند (بخش «منبع نرخ» را ببینید) و آن را به‌عنوان مرجع همه‌ی
محاسبات قرار می‌دهد:

- مقدار پیش‌فرض تومان همیشه **۱,۰۰۰,۰۰۰** است.
- مقدار پیش‌فرض دلار از روی همین نرخ واقعی محاسبه می‌شود (نه یک عدد ثابت).
- با تایپ در فیلد **تومان**، مقدار **دلار** بر اساس همان نرخ محاسبه می‌شود.
- با تایپ در فیلد **دلار**، مقدار **تومان** بر اساس همان نرخ محاسبه می‌شود.
- دکمه‌ی ⇅ ترتیب دو ردیف (کدام ارز بالا/پایین باشد) را عوض می‌کند و سرتیتر
  و نرخ نمایش‌داده‌شده هم با همین جهت هماهنگ می‌شوند.
- تا وقتی نرخ دریافت نشده، فیلد دلار و دکمه‌ی سواپ غیرفعال هستند (تا عددی
  نادرست یا گمراه‌کننده نمایش داده نشود).

### منبع نرخ

نرخ از فید JSON رایگان و بدون نیاز به کلید **rate-json / Tomanify** خوانده
می‌شود که نرخ بازار آزاد دلار به تومان را چند بار در روز به‌روزرسانی
می‌کند:

```
https://raw.githubusercontent.com/rate-json/default/main/data.json
```

این فید توسط «Tomanify» منتشر می‌شود (طبق شرایط استفاده‌ی این فید، منبع در
همین‌جا و در رابط کاربری اپ ذکر شده است):
<https://wordpress.org/plugins/tomanify>

اگر دریافت این فید با خطا مواجه شود (قطعی شبکه، مسدودشدن دامنه، تایم‌اوت
و…)، اپ به‌صورت خودکار از یک **نرخ پیش‌فرض جایگزین (۲۳۴,۴۰۰ تومان)** استفاده
می‌کند و این موضوع را صریحاً در یک پیام قرمز‌رنگ به کاربر اطلاع می‌دهد؛
هیچ‌وقت به کاربر یک عدد نادرست را بدون اطلاع‌رسانی نشان نمی‌دهد.

## رویکرد و مدل فکری

1. **نرخ دیگر دستی نیست.** در نسخه‌های قبلی این پروژه یک فیلد قابل‌ویرایش
   برای نرخ وجود داشت. طبق درخواست، این فیلد کاملاً حذف شد و به‌جایش نرخ
   واقعی از یک API عمومی خوانده می‌شود تا محاسبات به قیمت واقعی روز نزدیک
   باشد، نه یک فرض دستی.
2. **مدیریت خطا و حالت بارگذاری.** چون این یک درخواست شبکه‌ای واقعی است،
   حتماً باید حالت «در حال دریافت» و حالت «خطا» هم در نظر گرفته شود؛ در
   غیر این صورت با اولین قطعی اینترنت، اپ عددی اشتباه (یا `NaN`) نشان
   می‌داد. با AbortController یک timeout هشت‌ثانیه‌ای هم در نظر گرفته شده
   تا در صورت کندی شبکه، اپ بی‌نهایت منتظر نماند.
3. **حذف بخش «قیمت امروز» تکراری.** در نسخه‌ی قبلی که نرخ دستی بود، یک
   بخش جدا برای «قیمت امروز» با درصد تغییرات نمایشی وجود داشت تا نرخ واقعی
   را از نرخِ دستیِ کاربر متمایز کند. حالا که خودِ نرخ همیشه واقعی است، آن
   بخش کاملاً تکراری می‌شد (دقیقاً همان عددِ «نرخ تبدیل» را دوباره نشان
   می‌داد) و نگه‌داشتنش، مخصوصاً با درصدهای فرضی و ساختگی کنار یک عدد
   واقعی، گمراه‌کننده بود؛ به‌جایش یک خط وضعیت با تاریخ به‌روزرسانی و
   نام منبع اضافه شد.
4. **بدون فریم‌ورک.** HTML + CSS + TypeScript خام، بدون React/Vue و بدون باندلر.
5. **قالب نمایش اعداد بسیار کوچک.** برای نرخ‌هایی مثل تومان‌به‌دلار که عددی
   مثل `0.0000043` هستند، از نماد فشرده استفاده شده: `0.0₅4328` (یعنی پس از
   ممیز، ۵ صفر و سپس رقم‌های معنادار). این در تابع `formatCompactSmall`
   پیاده‌سازی شده است.

## باگ‌های رفع‌شده (در بازبینی‌های قبلی)

1. **ارقام فارسی/عربی نادیده گرفته می‌شدند.** کیبورد بیشتر گوشی‌های ایرانی
   پیش‌فرض روی ارقام فارسی است؛ تابع `normalizeDigits` این ارقام و
   جداکننده‌ی اعشاری آن‌ها را قبل از پردازش به معادل انگلیسی تبدیل می‌کند.
2. **دو فیلد مبلغ، برچسب دسترسی‌پذیری یکسان داشتند.** هر فیلد الان
   `aria-label` مجزا دارد («مبلغ به تومان» / «مبلغ به دلار») که با سواپ هم
   به‌روز می‌شود.
3. **جهت نوشتار پایه‌ی صفحه (dir) تنظیم نشده بود.** این باعث می‌شد متن‌های
   فارسیِ ترکیب‌شده با اعداد/کلمات لاتین (مثل نام منبع نرخ و تاریخ) با
   ترتیب اشتباه نمایش داده شوند. `dir="rtl"` روی `<html>` تنظیم شد و بخش‌های
   عددی خاص (مثل ردیف‌های ارز) با `dir="ltr"` محلی override شدند.

## ویژگی‌ها

- نرخ لحظه‌ای واقعی از یک API عمومی و رایگان (بدون نیاز به کلید)
- تبدیل دو‌طرفه‌ی زنده و درست بین تومان (IRT) و دلار (USD)
- دکمه‌ی جابه‌جایی جهت (⇅) با انیمیشن چرخش، بدون از‌دست‌رفتن مقادیر
- مدیریت کامل حالت بارگذاری و خطا (fallback + پیام شفاف به کاربر)
- فرمت‌دهی خودکار اعداد با جداکننده‌ی هزارگان
- پشتیبانی از ارقام فارسی/عربی در ورودی
- نمایش فشرده‌ی اعداد بسیار کوچک با نماد صفرِ زیرنویس (مثل `0.0₅4328`)
- کاملاً ریسپانسیو: از موبایل‌های کوچک (۳۲۰ پیکسل) تا تبلت و دسکتاپ تست شده

## تکنولوژی‌ها

- HTML5 / CSS3 خام
- TypeScript (کامپایل‌شده به JavaScript ساده، بدون ماژول)
- `fetch` API برای خواندن نرخ لحظه‌ای (بدون هیچ کتابخانه‌ی اضافه)
- بدون فریم‌ورک، بدون باندلر، بدون نیاز به Node در زمان اجرا

## ساختار پروژه

```
├── index.html          # صفحه‌ی اصلی
├── style.css           # استایل‌ها (شامل breakpointهای ریسپانسیو)
├── src/
│   └── main.ts         # دریافت نرخ زنده، منطق تبدیل، فرمت اعداد و رندر UI
├── dist/
│   ├── main.js          # خروجی کامپایل‌شده (همین فایل در index.html لود می‌شود)
│   └── main.js.map
├── tsconfig.json        # تنظیمات کامپایلر TypeScript
├── package.json         # فقط برای اسکریپت build در حین توسعه
└── .gitignore
```

## اجرای پروژه

چون پروژه کاملاً استاتیک است، نیازی به Node یا سرور خاصی برای *اجرا* نیست؛
کافی است فایل `index.html` را در مرورگر باز کنید یا با هر static server ساده‌ای
(مثلاً افزونه‌ی Live Server در VS Code) سرو کنید. توجه داشته باشید که برای
دریافت نرخ لحظه‌ای، دستگاه باید به اینترنت متصل باشد؛ در غیر این صورت اپ
به‌صورت خودکار از نرخ پیش‌فرض استفاده می‌کند.

### توسعه و تغییر سورس TypeScript (اختیاری)

اگر بخواهید فایل `src/main.ts` را تغییر دهید، باید دوباره آن را کامپایل کنید:

```bash
npm install        # نصب TypeScript به‌عنوان devDependency
npm run build       # ساخت مجدد dist/main.js
```

فایل خروجی کامپایل‌شده از قبل در ریپو موجود است، بنابراین این مرحله فقط برای
توسعه‌ی بیشتر لازم است، نه برای اجرای سایت.

## منابع استفاده‌شده

- فونت [Vazirmatn](https://github.com/rastikerdar/vazirmatn) از Google Fonts، فقط برای تایپوگرافی.
- آیکون‌های پرچم به‌صورت SVG داخلی (inline) ساخته شده‌اند، بدون هیچ فایل تصویری بیرونی.
- نرخ لحظه‌ی دلار به تومان از فید رایگان [rate-json (Tomanify)](https://github.com/rate-json/default)
  خوانده می‌شود؛ طبق شرایط استفاده‌ی این فید، منبع همین‌جا ذکر شده و در
  خودِ رابط کاربری اپ هم («نرخ لحظه‌ای از Tomanify») نمایش داده می‌شود.

## نکته درباره‌ی داده‌ها

- نرخ تبدیل، واقعی و لحظه‌ای است (نه فرضی)، اما چون از یک فید بازار آزاد و
  غیررسمی خوانده می‌شود، ممکن است با نرخ رسمی بانکی یا صرافی‌های مختلف
  اندکی تفاوت داشته باشد؛ این موضوع در متن UI هم با ذکر منبع شفاف شده است.
- اگر دریافت نرخ ناموفق باشد، از یک مقدار پیش‌فرض ثابت (۲۳۴,۴۰۰ تومان)
  استفاده می‌شود و این هم به‌وضوح به کاربر اطلاع داده می‌شود.
