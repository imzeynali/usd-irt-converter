# 💱 مبدل دلار به تومان/ریال

مبدل دوطرفه‌ی دلار آمریکا و تومان (یا ریال) ایران، با نرخ لحظه‌ای واقعیِ بازار آزاد — نه یک عدد ثابت و دستی.

---

## ✨ ویژگی‌ها

- 🔄 **تبدیل آنی و دوطرفه** — با تایپ در هر کدام از دو فیلد، مقدار دیگر بر اساس نرخ لحظه‌ای محاسبه می‌شود
- 📡 **نرخ لحظه‌ای واقعی** با زنجیره‌ی منبع پشتیبان؛ اگر منبع اصلی در دسترس نبود، اپ به‌صورت خودکار سراغ منبع بعدی می‌رود
- 🔁 **جابه‌جایی جهت تبدیل** با یک کلیک (دلار ⇄ تومان)
- ⚖️ **سوییچ تومان / ریال رسمی** با کلیک روی ردیف ارز ایرانی
- 🛡️ **محدودیت هوشمند ورودی** برای جلوگیری از سرریز رقم‌ها در اعداد بسیار بزرگ
- 📅 نمایش تاریخ شمسیِ روز
- 🔃 دکمه‌ی به‌روزرسانی دستیِ نرخ
- 📱 طراحی کاملاً ریسپانسیو، مناسب موبایل و دسکتاپ

## 🧱  فناوری های به کار رفته

| بخش | فناوری |
|---|---|
| زبان | TypeScript (کامپایل‌شده به ES2019) |
| رابط کاربری | HTML5 + CSS3 خالص (بدون فریم‌ورک) |
| فونت | Vazirmatn |
| وابستگی ران‌تایم | ندارد |

## 📁 ساختار پروژه

```
.
├── index.html          # ساختار صفحه
├── style.css            # استایل‌ها
├── src/
│   └── main.ts           # کل منطق برنامه
├── dist/
│   └── main.js           # خروجی کامپایل‌شده (تولیدشده از main.ts)
├── tsconfig.json
└── package.json
```

## 🚀 اجرا

```bash
npm install
npm run build   # کامپایل src/main.ts → dist/main.js
```

سپس `index.html` را در مرورگر باز کنید. پروژه کاملاً استاتیک است و به هیچ سرور یا بک‌اندی نیاز ندارد.

برای توسعه با کامپایل خودکار:

```bash
npm run watch
```

> کلید BrsApi به‌صورت مستقیم در `src/main.ts` (ثابت `BRSAPI_KEY`) قرار دارد. چون پروژه بدون بک‌اند است، این کلید در کد نهاییِ مرورگر قابل‌مشاهده است — برای استفاده‌ی شخصی مشکلی ندارد، اما در صورت انتشار عمومی با ترافیک بالا بهتر است با کلید اختصاصی خودتان جایگزین شود.

## ⚙️ معماری و منطق کار

نرخ ارز و تمام مقادیر داخلی همیشه بر مبنای **تومان** نگه‌داری می‌شوند؛ نمایش ریال صرفاً یک ضرب در ۱۰ در لایه‌ی نمایش است، نه یک واحد پایه‌ی جداگانه. این باعث می‌شود منطق تبدیل ساده و بدون خطای گرد کردن بماند.

ورودی کاربر (چه دلار، چه تومان/ریال) به یک سقف مشخص محدود می‌شود تا عدد معادل هیچ‌وقت آن‌قدر بزرگ نشود که از کادر بیرون بزند؛ در صورت عبور از سقف، مقدار به‌صورت خودکار محدود شده و به کاربر اطلاع داده می‌شود.

### زنجیره‌ی منابع نرخ

نرخ به ترتیب از منابع زیر خوانده می‌شود؛ در صورت شکست هر منبع (قطعی، تایم‌اوت، پاسخ نامعتبر)، به‌صورت خودکار به منبع بعدی سوییچ می‌شود:

1. **[BrsApi.ir](https://brsapi.ir)** — قیمت لحظه‌ای دلار در بازار آزاد
2. **[Nobitex](https://api.nobitex.ir)** — به‌عنوان پشتیبان، نرخ لحظه‌ای تتر (USDT) خوانده و با یک ضریب اختلافِ ثابت (`USD_PREMIUM_OVER_USDT` در `main.ts`) معادل نرخ دلار نقدی محاسبه می‌شود
3. در صورت شکست هر دو منبع، یک نرخ تقریبیِ آفلاین به‌کار می‌رود و این موضوع صراحتاً به کاربر اطلاع داده می‌شود
